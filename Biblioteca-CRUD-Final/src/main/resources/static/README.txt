BIBLIOTECA+ — FRONTEND FINAL

Este frontend foi preparado para o backend Spring Boot com as rotas:
/alunos
/livros
/emprestimos
/emprestimos/{id}/devolver

COMO USAR NO PROJETO:
1. Abra seu projeto Spring Boot.
2. Vá até src/main/resources/static
3. Substitua o conteúdo da pasta static pelos arquivos deste ZIP.
4. Execute: .\mvnw spring-boot:run
5. Abra: http://localhost:8080/

O frontend começa vazio e os livros podem ser adicionados depois pela tela Livros.
